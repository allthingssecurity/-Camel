## What is specified

- Uri.v (hand-written, 50 tagged rules: 39 DOC, 8 CODE, 3 DOC-BUG): URI lexing (scheme = text before the first `:`,
  `//`, path / query, `&`-separated `name=value`, empty parameters, `RAW(...)` / `RAW{...}`, percent-decoding, `+`),
  path parameters by the component's `syntax`, option names (exact, ignore case, multiValue prefix, lenient, unknown,
  `hash`), option values by JSON type/javaType (string, boolean, integer, number, duration syntax, enum in any style,
  references and objects UNSPECIFIED), defaults, required options; endpoint creation (`creates`, `run_ep`, proved
  sound: `run_ep_sound`) and the catalog tools (`validates`, `cat_validate`, proved sound: `cat_validate_sound`;
  `cat_props`, `cat_asuri`, `cat_name`).
- GenCatalog.v (generated by tools/gen_l5.py, data only): 415 components, 11 101 endpoint option rows (name, kind,
  type, javaType class, required, default, enum, multiEnum, prefix/multiValue, optionalPrefix, secret), 225 shared enum
  lists, the required component options, and the `api` flag. 1.3 MB; compiles in ~6 s at ~570 MB (no lock needed).
- Catalog.v: the rules on the real tables, 30 documented examples (vm_compute), the L5b constraints met at the pin,
  the theorems `lenient_no_rfe` (+ lemmas) with non-vacuity examples, and the Real mode (`run_real`,
  `cat_validate_real`: rules + open findings as deltas).
- The JSONs are stored as docs/component-json/catalog-components.tar.xz (the 415 catalog JSONs, 13.5 MB raw, 0.63 MB
  compressed); citations `[CJ:<file>.<line>]` are lines of the members. The uncompressed copies in docs/component-json
  are the ones cited most (5 were already there for L2).

## Running

    bash oracle/l5/build.sh                  # gen + compile + extract + OCaml driver (light)
    bash harness/build-camel.sh              # (once) core + 7 components at the pin (main session's script)
    bash harness/l5/build-catalog.sh         # (once) camel-catalog + core-catalog + tooling-model at the pin, 3 s, 29 MB
    [MODE=real] bash harness/l5/run.sh <label> E|C all <seed> <count>

tools/status.py does not mix them into the L2 rows; see requests).

## Doc bugs and doc gaps (for findings/doc-bugs.md)

1. endpoint.adoc line 128: `file://inbox?idempontentRepository=#type:...` misspells `idempotentRepository`; as written
   the option is unknown (Catalog.v doc_idempotent_typo).
2. endpoint.adoc line 139: `direct:start?paramA=1&paramB=2` (an XML-escaping illustration) fails as a URI: direct has
   no such options (doc_direct_xml_escaping). Suggest a real option (e.g. `timeout=1000&block=false`).
3. camel-3x-upgrade-guide-3_2.adoc lines 444-449: "Endpoint URIs without context path ... will throw an
   NoSuchEndpointException": no longer true (see L5.ep.no-colon); the 3.2 guide is historical, but no later page says
   the current behaviour.
4. camel-4x-upgrade-guide-4_23.adoc lines 1707-1708: "A query parameter named `hash` ... is now kept as a regular
   parameter": reverted by 36f06e1370b7 the next day; the guide still says kept.
5. log logMask: Default `false` in the table, really "unset: the CamelContext's logMask".
6. controlbus `language` path option: the enum list [CJ:controlbus.json] lacks `variable` (and is a static list in
   @UriPath(enums=...)); `controlbus:language:variable` works (150 cases).
7. Path options that the syntax does not place: azure-files (port, directoryName), tahu-edge (deviceId), wordpress
   (operationDetail).
8. Undocumented constraints that fail endpoint creation: log groupSize / groupInterval must be positive, mock
   reportGroup must be positive (IllegalArgumentException "must be positive"); seda size <= 0 uses the default.
9. endpoint.adoc lines 216-217: "a plus sign ... would be decimal encoded by default" does not say what happens: a
   `+` is a space (form decoding).
10. CamelCatalog.endpointComponentName javadoc "or null if not possible to determine": `:x` gives "" (empty), `neo4j`
    (no colon) null.
11. API components: the JSON `apiName` enum lists `DRIVE_REPLIES` (google-drive), but the catalog validation reports
    it as an invalid enum value (it takes the `apis` names, `drive-replies`); body-types.adoc 435-436 says enum values
    compare "in any style". Candidate for the catalog or for the JSON (not differentially checked at runtime: the
    component is not compiled here).
12. The catalog gives a single path part to the last optional name when no name is required (`smpp:myhost` -> port
    myhost, then "invalid integer port"); runtime not checked (smpp not compiled). Recorded, UNSPECIFIED.
